# TRINETRA
TRINETRA uses dual I2S microphones with Environmental Noise Fingerprinting and adaptive thresholds for robust wake-word detection. ACWE cascades Energy Gate, VAD and TinyML KWS using an INT8 DS-CNN. Multi-frame validation triggers audio streaming to online ASR or local ASR, with offline queuing, auto-sync, telemetry-grounded SLM, TTS and analytics.
